# Weddings By Siddhant Kapoor website

The code for the new WBSK website and WBSK Studio: a static Next.js site, published to GitHub Pages.

No production deployment or domain changes are allowed without explicit owner approval. This repository never holds secrets.

```bash
npm ci
npm run dev
```

`npm run check` runs the code checks, and `npm run test:e2e` runs the browser tests against a build.
